# Portfólio - Giovani Gama

Portfólio profissional desenvolvido com HTML, CSS e JavaScript puro.

## 🚀 Características

- **Design Responsivo**: Funciona perfeitamente em desktop, tablet e mobile
- **Animações Suaves**: Transições e efeitos visuais modernos
- **Performance Otimizada**: Código limpo e otimizado
- **Acessibilidade**: Estrutura semântica e navegação por teclado
- **SEO Friendly**: Meta tags e estrutura HTML otimizada

## 📁 Estrutura do Projeto

```
portfolio/
├── index.html      # Estrutura HTML principal
├── styles.css      # Estilos CSS
├── script.js       # Interatividade JavaScript
└── README.md       # Documentação
```

## 🎨 Seções

1. **Hero/Apresentação**: Introdução com nome, título e call-to-action
2. **Sobre**: Resumo profissional e objetivos
3. **Experiência**: Timeline interativa com histórico profissional
4. **Formação**: Cards com formação acadêmica
5. **Skills**: Categorias de habilidades técnicas e soft skills
6. **Contato**: Links para redes sociais e e-mail

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3 (Flexbox, Grid, Animations)
- JavaScript (ES6+)
- Google Fonts (Inter)

## 📱 Responsividade

O portfólio é totalmente responsivo com breakpoints em:
- Desktop: > 768px
- Tablet: 480px - 768px
- Mobile: < 480px

## 🚀 Como Usar

1. **Abrir localmente**:
   - Abra o arquivo `index.html` diretamente no navegador

2. **Usar com servidor local** (recomendado):
   ```bash
   # Python 3
   python -m http.server 8000
   
   # Python 2
   python -m SimpleHTTPServer 8000
   
   # Node.js (com http-server)
   npx http-server
   ```
   Depois acesse: `http://localhost:8000`

3. **Deploy**:
   - **GitHub Pages**: Faça upload para um repositório e ative GitHub Pages
   - **Netlify**: Arraste a pasta para o Netlify Drop
   - **Vercel**: Conecte o repositório ao Vercel
   - **Surge**: `npm install -g surge && surge`

## ✏️ Personalização

### Alterar Cores

Edite as variáveis CSS em `styles.css`:

```css
:root {
    --primary-color: #6366f1;
    --secondary-color: #8b5cf6;
    /* ... outras cores */
}
```

### Adicionar/Remover Seções

Edite o arquivo `index.html` e ajuste a navegação correspondente.

### Modificar Informações de Contato

Atualize os links na seção de contato no `index.html`:

```html
<a href="mailto:seu-email@exemplo.com" class="contact-btn">
    <!-- ... -->
    E-mail
</a>
```
